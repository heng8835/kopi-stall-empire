# ChatGPT prompts: walk-ins, Horlicks tin, opening backgrounds (2026-10-25)

What they are for: `docs/specs/opening-and-art-plan.md`. Style rules: `docs/ART_BIBLE.md`.
**10 images (+1 optional), split into 6 short sittings of 1–2 images.** Do one sitting a day if you like.

## How to use (saves usage)
- **One new chat per sitting.** Attach **`art/source/owner-jun-mei.webp`** once, at the start.
  Every later prompt in that chat says "same style as the attached image".
- 4 walk-ins share one image. Ask for **landscape (1536x1024)**. Backgrounds: **portrait (1024x1536)**.
- If one character comes out wrong, don't redo the whole image. Ask:
  *"Keep everything the same, only redo character 3: …"*
- Save each result into `art/source/` with the file name given below, then tell me. I do the cutting and sizing.
